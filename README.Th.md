# Awesome OSINT (รายชื่อเครื่องมือ OSINT ที่ยอดเยี่ยม)

[<img src="https://github.com/jivoi/awesome-osint/raw/master/osint_logo.png" align="right" width="100">](https://github.com/jivoi/awesome-osint)

รายการรวบรวมเครื่องมือและแหล่งข้อมูล open source intelligence (OSINT) ที่ยอดเยี่ยม
[Open-source intelligence (OSINT)](https://en.wikipedia.org/wiki/Open-source_intelligence) คือข่าวกรองที่รวบรวมจากแหล่งที่สาธารณะ
ในวงการข่าวกรอง (Intelligence Community: IC) คำว่า "open" หมายถึงแหล่งข้อมูลที่เปิดเผย และเข้าถึงได้สู่สาธารณะ (ตรงข้ามกับแหล่งลับหรือปิดบัง)

ลิสต์นี้จัดทำขึ้นเพื่อช่วยทุกท่านที่สนใจ Cyber Threat Intelligence (CTI), การตามล่าหาภัยคุกคาม และ OSINT ทั้งผู้เริ่มต้นและผู้มีประสบการณ์

ขอให้ใช้งานและแฮกอย่างมีความสุข 🧙‍♂️
